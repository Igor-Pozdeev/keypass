# KeyPass Chrome Plugin

KeyPass - это плагин для Google Chrome, который помогает управлять паролями и автоматически заполнять формы входа на сайтах.

## Особенности

- Хранение паролей в зашифрованном виде
- Автоматическое заполнение форм входа
- Удобный интерфейс для управления паролями
- Поддержка поиска и фильтрации паролей
- Возможность копирования паролей в буфер обмена

## Установка

1. Склонируйте репозиторий или скачайте архив с плагином
2. Откройте Chrome и перейдите по адресу `chrome://extensions`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку с плагином

## Использование

1. Нажмите на значок KeyPass в панели инструментов Chrome
2. В появившемся окне вы увидите список сохраненных паролей
3. Для добавления нового пароля нажмите кнопку "Добавить пароль"
4. Для копирования пароля нажмите кнопку "Копировать" рядом с нужным паролем

## Структура плагина

- `manifest.json` - основной файл конфигурации плагина
- `popup.html` - интерфейс всплывающего окна
- `popup.js` - логика работы всплывающего окна
- `content.js` - скрипт, выполняющийся на страницах
- `background.js` - фоновый скрипт для обработки событий
- `styles.css` - стили для интерфейса
